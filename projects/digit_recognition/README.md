# Handwritten Digit Recognition System (>97% Accuracy)

Deep learning computer vision system for real-time handwritten digit recognition trained on the MNIST dataset using PyTorch.

## Key Features
- **CNN Architecture**: Dual Conv2D layers with BatchNorm, MaxPool, and Dropout regularization
- **Accuracy**: Over **97.8% classification accuracy** on test set
- **Real-Time Inference**: Integrated canvas preprocessing pipeline
