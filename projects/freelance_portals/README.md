# Freelance Client Web Portals

Highly optimized, lightweight single-page landing portals developed for freelance clients. Features custom responsive CSS structures, zero external library dependencies (for fast rendering), and a structure designed for lifetime free hosting (GitHub Pages, Netlify, or Vercel).

## 🚀 Running the Code - Step-by-Step Instructions

### Step 1: Open Locally in Browser
Because this page is built using pure static vanilla HTML5/CSS3 and JavaScript, it does not require a local server to run.
1. Simply double-click `index.html` on your computer.
2. It will open in your default browser (Chrome, Firefox, Safari, Edge).
3. Click the **Trigger Lifetime Action** button to test the JavaScript event handler.

### Step 2: Running with a Live Reload Server (Optional)
If you are developing/modifying this template and want a live reload environment:
1. Ensure Node.js is installed. Install `live-server` globally:
   ```bash
   npm install -g live-server
   ```
2. Navigate to this directory and run the command:
   ```bash
   live-server
   ```
3. Your browser will automatically open `http://127.0.0.1:8080` and update the view instantly whenever you modify `index.html` or `app.js`.

### Step 3: Deploying with Free Lifetime Hosting
When delivering these projects to freelance clients, you can host them permanently for free:
* **Option A: Netlify (Drag and Drop)**
  1. Go to [Netlify App](https://app.netlify.com).
  2. Drag and drop this folder directly into the deploy box.
  3. Netlify will deploy the files in seconds and give you a free, public URL.
* **Option B: GitHub Pages**
  1. Push these files to a public GitHub repository.
  2. Navigate to **Settings** > **Pages** in the repository tabs.
  3. Select the `main` branch as the source and click **Save**.
  4. Your site will be live at `https://username.github.io/repo-name`.
